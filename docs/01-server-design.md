# Server Design

## Objective
Design a maintainable home server rather than installing unrelated applications.

## Roles
- Linux operating system
- data/media storage
- container runtime
- media service
- file sharing as needed
- monitoring
- backup/recovery

## Design Questions
Document storage layout, users/groups, service exposure, backup destination, update process, and failure/recovery plan.

## Evidence
Create a simple architecture diagram and hardware/storage inventory.
